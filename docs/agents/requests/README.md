# Shared Change Requests

This directory holds cross-lane change requests addressed to Agent A (Platform & Landing Page Integrator).

### Format: `<from>-to-A-<n>.md`
Example: `B-to-A-1.md`

Each request must detail:
1. **Target File(s)**: Shared file requiring changes.
2. **Rationale**: Why local adaptation or world manifest extension is insufficient.
3. **Exact Additive Change**: Non-breaking, optional parameter with Level 1 default.
