# Project Rules: ASD-STE100 (Simplified Technical English)

All user-facing copy, game instructions, UI text, mascot dialog, feedback messages, and documentation in EcoSort must follow the **ASD-STE100** specification.

---

## 1. Core Principles

1. **One Idea Per Sentence**: Express only one single idea or instruction in each sentence.
2. **Short Sentences**:
   - In-game child text / mascot dialogue: **8 words or fewer**.
   - Instructions / UI labels: **20 words or fewer**.
   - Descriptions / documentation: **25 words or fewer**.
3. **Active Voice**: Always use active voice.
   - *Good:* "Throw the bottle in the blue bin."
   - *Bad:* "The bottle should be thrown into the blue bin."
4. **Simple Present Tense**: Use simple present tense. Avoid continuous verbs or complex verb chains.
5. **Direct Warnings**: Write **"Do not"** for warnings and negative instructions. Avoid contractions (do not write "Don't", "Can't", "Won't").
6. **Consistent Terminology**: Use the exact same word for the same concept across the entire application.
   - Always use **"bin"** (never switch between "container", "box", "can", "bucket").
   - Always use **"waste"** (never switch between "garbage", "trash", "rubbish").
7. **Preserve Articles**: Keep all articles (`a`, `an`, `the`). Do not omit articles to save space.
8. **No Slang or Idioms**: Avoid colloquialisms, jargon, and figurative language.

---

## 2. In-Game Dialogue Rules (Mascot & Feedback)

- Maximum length: **8 words per sentence**.
- Provide a clear reason for every feedback response.
- Examples:
  - *Correct answer:* "Great job! Food waste becomes compost."
  - *Wrong answer:* "Stop! Put the battery in the red bin."
